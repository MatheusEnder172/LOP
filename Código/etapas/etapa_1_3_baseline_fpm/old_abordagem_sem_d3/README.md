# Arquivos da Abordagem Antiga (Base Mássica sem divisão por D³) — Etapa 1.3

Em conformidade com a **Regra 5 de Governança do Projeto LOP**, esta pasta preserva os scripts originais da Etapa 1.3 antes da introdução da nova abordagem `RRB ÷ D³` e do White-Box Puro sem amortecimento empírico (`α = 0`).
- **Arquivos preservados**: Versão original de `simular_baseline_fpm.py`, `gerar_comparativo_ensaios_individuais.py`, `gerar_comparativo_fabricio_vs_novo.py` e `test_pbm_batch.py`.
- **Motivo**: O Baseline FPM oficial do projeto foi atualizado para utilizar a distribuição `RRB ÷ D³` sem o parâmetro artificial `α` (`α = 0`), elevando o ajuste global de `r² = 0,9030` (`RMSE = 10,10%`) para `r² = 0,9590` (`RMSE = 6,56%`).
