# Preservação Histórica — Scripts da Etapa 3.1 (Abordagem Antiga sem Divisão por D³)

## 1. Contexto e Motivação
Este diretório preserva os scripts originais de partição e pré-processamento de dados antes da adequação à nova base de alvos com `RRB ÷ D³`.

## 2. Conteúdo Preservado
- `executar_particao.py`: Script original de geração dos splits e ajuste de scalers.
- `test_preprocessing.py`: Bateria de testes unitários para verificação de data leakage e integridade dos splits.
- `README.md`: Documentação técnica original da etapa.
